Make the first report path free. The standalone sample pack and role-based HTML reduce adoption friction; they are not a defensible paid gate. Do not create a new report SKU, per-report fee, per-seat view fee, telemetry requirement or hosted account dependency.

Paid value remains sustained analysis depth and organizational adoption—not new runtime authority. All reader perspectives use the same report facts. No edition-specific schema or hidden governance outcome is introduced.
